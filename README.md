# 🤖 Curso Análisis de Datos y Machine Learning con Python - Módulo 1: Programación en Python

Bienvenido/a al módulo 1 del curso "Análisis de Datos y Machine Learning con Python", el cual está diseñado para personas interesadas en aprender a programar en Python.

## 🎯 Objetivo del curso

Aprender a programar en Python desde cero: sintaxis, tipos de objetos, estructuras de datos, condicionales, bucles, funciones y manejo de errores, además del uso de Google Colab, Visual Studio Code, ambientes virtuales y control de versiones con Git y GitHub.

## 📚 Estructura de contenidos

1. Introducción y conceptos fundamentales
2. Entorno de trabajo
3. Gestión de información y tipos de objetos
4. Lógica de programación, condicionales, bucles, creación de funciones y manejo de errores

## 🛠 Herramientas utilizadas

- Python
- Jupyter Notebook 
- Google Colab (programación en la nube sin instalaciones)
- Visual Studio Code
- Git y GitHub (control de versiones)

## 📌 Requisitos previos

- Conocimientos básicos de estadística y economía.
- Nociones generales de análisis de datos.
- No es necesario saber programar previamente (el curso incluye fundamentos de Python).
- Cuenta de Gmail para usar Google Colab.
- Cuenta de Github.

## 📅 Modalidad

**Duración:** 12 horas presenciales.

**Metodología:** El curso combina práctica guiada y trabajo autónomo.
